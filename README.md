# Sustainable Phishing Email Classifier

A professional, modular machine learning project designed to classify emails as **Phishing** or **Legitimate** while benchmarking classification performance against computational efficiency and environmental impact (Green AI).

This repository trains, evaluates, and compares six classifier models:
1. **LR Word**: Logistic Regression on word-level TF-IDF (1-2 n-grams).
2. **SVM Char**: LinearSVC on character-level TF-IDF (3-5 n-grams).
3. **HistGradientBoosting (HGB)**: HistGradientBoostingClassifier utilizing engineered numeric features (e.g., text lengths, digit counts, URL counts).
4. **MobileBERT**: Light-weight Transformer fine-tuned on the primary text column.
5. **DistilBERT**: Knowledge-distilled BERT transformer fine-tuned on the primary text column.
6. **Electra**: Discriminator-based Electra transformer fine-tuned on the primary text column.

---

## Key Sustainability & Benchmarking Features

To promote sustainable and efficient AI deployment, this project integrates [CodeCarbon](https://codecarbon.io/) to profile each classifier across multiple dimensions:
* **Predictive Metrics**: Accuracy, Precision, Recall, F1-Score, and ROC AUC.
* **Compute Performance**: Single-instance inference latency (ms) and throughput (emails/second).
* **Model Footprint**: Serialized model disk size (MB) for resource-constrained environments.
* **Environmental Impact (Green AI)**: Real-time carbon footprint monitoring (milligrams of CO2 equivalent, or $\text{mg } \text{CO}_2\text{eq}$) using CodeCarbon's `OfflineEmissionsTracker`.

## How to Run

### 1. Training the Pipeline
To load the dataset, perform stratified train-test splits, train all six models (including fine-tuning transformer architectures), print comparison metrics, and serialize the trained classifiers to `models/`, run:
```bash
python main.py
```

### 2. Evaluating, Benchmarking & Visualizing
To benchmark predictive metrics, inference latency, throughput, model disk footprint, and carbon emissions for all six models:
```bash
python visualize.py
```
This command outputs a terminal summary table and generates/updates two visual artifacts:
* **`performance_comparison.png`**: A static 3x2 grid of matplotlib charts showcasing the trade-offs (including Carbon Footprint in green).
* **`benchmark_report.html`**: A dark-themed, glassmorphic interactive dashboard powered by Chart.js. It features interactive graphs, detailed comparison tables, and a **Deployment & Sustainability Recommendation** based on the benchmark results.

### 3. Running Inference on Single Emails
To test individual emails using any of the trained classifiers, run `predict.py` with custom text:

```bash
# Using the default character-level SVM model (SVM Char)
python predict.py --subject "Urgent security update required" --body "Please verify your credentials at http://fake-login.com"

# Using a Transformer model (e.g. MobileBERT)
python predict.py --model mobilebert --subject "Verify Account" --body "Check out http://unsecure-portal.com to confirm your details."
```

### 4. Inspecting the Dataset
To inspect raw data structure, labels, language distribution, and null values, run the utility script:
```bash
python inspect_data.py
```

## Green AI Deployment Trade-offs

Here is a summary of the benchmarking results showing the critical balance between classification performance and environmental impact:

| Model Classifier | Accuracy | F1-Score | Latency | Throughput | Size | CO2 Footprint |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **LR Word** | 97.65% | 97.60% | 0.25 ms | 3988.3/s | 10.79 MB | 6.63 mg |
| **SVM Char** | 99.07% | 99.05% | 0.57 ms | 1746.5/s | 8.63 MB | 12.96 mg |
| **HGB Numeric** | 81.38% | 80.48% | 3.28 ms | 304.6/s | 0.34 MB | 9.70 mg |
| **MobileBERT** | 98.26% | 98.24% | 21.17 ms | 47.2/s | 94.59 MB | 2046.00 mg |
| **DistilBERT** | 98.62% | 98.60% | 24.98 ms | 40.0/s | 256.10 MB | 2377.59 mg |
| **Electra** | **99.40%** | **99.39%** | 48.55 ms | 20.6/s | 418.35 MB | 4692.44 mg |

### Key Trade-offs:
* **Accuracy/F1 Winner**: **Electra** delivers the highest predictive F1-score (**99.39%**), followed closely by **SVM Char** (**99.05%**).
* **The LLM Carbon Cost**: While **Electra** is the most accurate, it consumes **4692.44 mg of CO2eq** per benchmark run—which is **~360x higher** than **SVM Char** and **~700x higher** than **LR Word**. It is also **~85x slower** in inference latency than **SVM Char**.
* **Green AI Winner**: **SVM Char** (LinearSVC on char-level TF-IDF) represents the sweet spot for general deployment. It achieves **99.05% F1-score** (virtually identical to the heavy transformer models) while requiring only **0.57 ms** of latency and emitting a mere **12.96 mg of CO2eq**.
