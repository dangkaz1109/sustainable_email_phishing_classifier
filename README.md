# Sustainable Phishing Email Classifier

A professional, modular machine learning project designed to classify emails as **Phishing** or **Legitimate** while benchmarking classification performance against computational efficiency and environmental impact (Green AI).

This repository trains, evaluates, and compares three classifier models:
1. **LR Word**: Logistic Regression on word-level TF-IDF (1-2 n-grams).
2. **SVM Char**: LinearSVC on character-level TF-IDF (3-5 n-grams).
3. **HistGradientBoosting (HGB)**: HistGradientBoostingClassifier utilizing engineered numeric features (e.g., text lengths, digit counts, URL counts).

---

## Key Sustainability & Benchmarking Features

To promote sustainable and efficient AI deployment, this project integrates [CodeCarbon](https://codecarbon.io/) to profile each classifier across multiple dimensions:
* **Predictive Metrics**: Accuracy, Precision, Recall, F1-Score, and ROC AUC.
* **Compute Performance**: Single-instance inference latency (ms) and throughput (emails/second).
* **Model Footprint**: Serialized model disk size (MB) for resource-constrained environments.
* **Environmental Impact (Green AI)**: Real-time carbon footprint monitoring (milligrams of CO2 equivalent, or $\text{mg } \text{CO}_2\text{eq}$) using CodeCarbon's `OfflineEmissionsTracker`.

## How to Run

### 1. Training the Pipeline
To load the dataset, perform stratified train-test splits, train all three models, print comparison metrics, and serialize the trained classifiers to `models/`, run:
```bash
python main.py
```

### 2. Evaluating, Benchmarking & Visualizing
To benchmark predictive metrics, inference latency, throughput, model disk footprint, and carbon emissions for all three models:
```bash
python visualize.py
```
This command outputs a terminal summary table and generates/updates two visual artifacts:
* **`performance_comparison.png`**: A static 3x2 grid of matplotlib charts showcasing the trade-offs (including Carbon Footprint in green).
* **`benchmark_report.html`**: A dark-themed, glassmorphic interactive dashboard powered by Chart.js. It features interactive graphs, detailed comparison tables, and a **Deployment & Sustainability Recommendation** based on the benchmark results.

### 3. Running Inference on Single Emails
To test individual emails using any of the trained classifiers, run `predict.py` with custom text:

```bash
# Using the default character-level SVM model (SVM Char)
python predict.py --subject "Urgent security update required" --body "Please verify your credentials at http://fake-login.com"

# Using the Logistic Regression model (LR Word)
python predict.py --model lr_word --subject "Project meeting" --body "Hey Team, let's meet tomorrow at 10 AM to discuss the timeline."

# Using the HistGradientBoosting model (engineered numeric features)
python predict.py --model hgb --body "Verify your account immediately: http://phish-link.org/reset"
```

## Green AI Deployment Trade-offs

* **Accuracy/F1 Winner**: **SVM Char** delivers the highest predictive accuracy and F1-score. However, it incurs higher inference latency, requires a larger disk footprint, and has a higher carbon emission rate due to character n-gram transformations.
* **Sustainability & Compute Winner**: **HistGradientBoosting** (utilizing engineered numeric features) is highly recommended for resource-constrained environments or high-throughput/low-latency endpoints. It offers blazing-fast single-instance latency, high email throughput, a tiny disk footprint, and minimal energy consumption/carbon footprint.
